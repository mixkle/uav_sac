# 条件分布诊断

完整统计见conditional_summary.csv和总报告，原始64次运动与评分样本在conditional_samples_*.npz，未将空候选填零作为真实评分。

同状态条件采样不支持“扩散方差比Gaussian大”：best池D best的缩放位移方差迹35.20 m²，对比G best45.47 m²。扩散best→last的均值位移增加、方差略降，更应审查均值/方向随训练的漂移。高评分排序一致性也未导致更差的单步评分效果。

几何重算见geometric_risk_summary.csv：仅改变采样运动并精确重算UU/UG距离，best池中D best任一新增断联概率8.584%，G best10.400%。这同样反对“D在每个共同状态都更容易断联”的简单解释。原轨迹D大幅骤降更多，与访问的布局分布、关键锚点和长期演化有关，不能仅归因于同状态一次动作的噪声风险。incumbent_users_exposed仅表示原服务节点断联暴露的人数，不扣除其他UAV可能救回的用户，不等于实际覆盖损失。

完整噪声0.8干预见noise_paired_comparison.csv：D best覆盖−0.594个百分点，区间跨零；D last+0.693个百分点，区间跨零。G last小幅改善+0.520个百分点，区间[+0.033,+1.077]；不能据此宣称所有噪声缩小都无效，也未支持它能解决D与G best的差距。

下一步不默认继续降低噪声；优先结合多步分叉和几何断链案例检查运动均值、布局访问分布、关键链路与价值排序。当前样本是单训练种子开发验证状态，不能否定所有分布或噪声设计。
