# 断联惩罚权重0／0.1／0.5／2／5：1M训练验证

三组新训练均由用户完成，种子0、各1M条联合转移、489轮PPO。完整结果和恢复文件下载，冻结best／last，统一32场景10000–10031、采样种子880001、16环境、CUDA FP32／关闭TF32复验。原mu=0和0.1复用来源一致的同口径评估。未使用保留测试集，未重训或微调。

全部组为3邻居、容量10、共享连续Gaussian MAPPO、中心UE初始化、移动UE、时间因子critic。奖励为coverage＋0.1tau−mu D，鲁棒性与边界权重均为0。**本轮不应用近期的跳数减速或链路安全过滤器**，避免把执行干预混入奖励训练对照。

## 主要判断

1. **当前单种子、1M预算下，mu=0.1的服务与稳定性取舍最好。** 相对mu=0，last覆盖+2.85pp、吞吐+29.56Mbps，同时断联率下降4.42pp，最大单步跌幅均值下降13.21pp；相应场景区间未跨零。不是跨训练种子的最优权重证明。
2. **mu=0.5没有进一步提高服务能力。** 相对0.1，last覆盖-4.59pp、吞吐-49.53Mbps；平均断联率几乎相同（9.25%对9.31%）。最大单步跌幅进一步降低7.62pp，体现服务与风险的取舍。
3. **mu=2／5明显倾向保守联网。** last平均断联分别降至4.94%／5.76%，但覆盖降至43.31%／46.30%，后100步仅37.30%／41.44%。当前结果支持“更强断联成本能减少断联，却可能牺牲展开与服务”，不支持“权重越大覆盖越好”。
4. **强惩罚组仍会退化，退化不一定由断联造成。** mu=2／5的后100步相对51–150步分别为-14.13pp／-11.73pp。感知率均值从mu=0的86.96%下降到61.74%／66.36%，最近邻<100m的UAV比例升至10.44%／10.74%，mu=0.1为3.41%。这些统计与固定拓扑的聚集现象一致。

断联一架UAV时，mu=2／5的单步成本分别相当于16.67／41.67个UE的覆盖贡献（忽略吞吐），每架容量仅10。这使联网目标具有很强的取舍力度；D对所有断联UAV同等计数，不直接表达关键链路余量或展开价值。较小骤降还会受到整体覆盖较低的影响，需要与绝对覆盖和吞吐共同判断。

## 来源与解释限制

新增三组best和last覆盖、训练回报、吞吐均复现各自训练期CUDA记录（最大绝对误差<1e-6）。原mu=0在CPU训练，本轮使用其CUDA复验覆盖56.43844%；没有混用历史CPU覆盖58.63125%。其余四组CUDA训练。训练设备及随机流差异仍需考虑，单训练种子不能支持唯一根因判断。

强惩罚可能改变联网与展开的取舍。评价时同时看共同覆盖、吞吐、尾段覆盖、极端跌幅与断联，并用聚集和固定拓扑检查是否通过牺牲展开换取联网。D是断联UAV比例，奖励没有直接约束链路余量或单步覆盖跌幅。
