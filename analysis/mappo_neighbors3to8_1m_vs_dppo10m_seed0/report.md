# 1M baseline邻居数3–8与DPPO 10M：best模型比较

仅比较上述七组best，不加入baseline 10M、teacher、旧DPPO阶段或其他奖励消融。新6／7／8邻居完整运行已下载，冻结best复验；3／4／5和DPPO复用SHA256一致的同口径验证。

统一32场景10000–10031、400步、动作采样种子880001、批次16、CUDA FP32、关闭TF32。所有组使用容量10、中心UE初始化、移动UE，奖励为覆盖率＋0.1归一化吞吐，无断联／鲁棒性／边界奖励。保留测试集未使用。本轮未更新任何模型。

## 主要结论

1. **增加邻居信息对当前baseline有帮助，但不是单调关系。** 8邻居平均覆盖比3邻居高6.62pp，吞吐高54.57Mbps；7邻居却低于6邻居。不能据此认为每多一个邻居都必然提高收益。
2. **8邻居baseline与DPPO的覆盖差距已很小。** DPPO全程覆盖高0.84pp；后100步为66.34%对66.46%，终态为66.77%对68.06%。覆盖差的配对场景区间跨零，当前验证没有显示明确覆盖优势，但也不能证明两者等价。
3. **DPPO更突出的差异是数据率。** 相对8邻居吞吐高63.39Mbps（12.17%），场景区间[34.34, 91.78]Mbps。这一现象与DPPO可以选择关联和布局相容，但本对照没有隔离关联、策略结构和训练预算的贡献。
4. **平均部署维持改善，极端断链仍未解决。** 8邻居的后100步覆盖比51–150步高2.52pp，但32/32场景仍发生至少一次≥10pp单步骤降；每回合次数从3邻居33.38降到12.69，单回合最大跌幅均值仍为42.46pp。DPPO也有31/32场景出现该类事件。
5. **论文需要更强的邻居观测对照。** 不能只把DPPO与3邻居baseline的差值解释为新算法收益；后续正式算法对比应统一邻居信息与训练预算，保留当前3–8邻居结果作为观察范围敏感性分析。


## 邻居数的影响

当前单种子运行中，平均覆盖最高的baseline为8邻居（63.054%）。以下均为相对3邻居的配对场景差值，95%区间来自2000次场景bootstrap（种子950001）。

- 4邻居：平均覆盖+3.838pp，区间[+1.289, +6.244]pp；吞吐+38.58Mbps。
- 5邻居：平均覆盖+4.242pp，区间[+1.606, +6.804]pp；吞吐+40.41Mbps。
- 6邻居：平均覆盖+5.875pp，区间[+3.234, +8.522]pp；吞吐+45.35Mbps。
- 7邻居：平均覆盖+2.924pp，区间[-0.194, +5.929]pp；吞吐+24.08Mbps。
- 8邻居：平均覆盖+6.615pp，区间[+3.989, +9.430]pp；吞吐+54.57Mbps。

不能把邻居更多直接等同于性能更好。邻居输入增加了可见信息，也扩大第一层参数量；每组只有一个训练种子，best选模还依赖固定验证集。区间只描述这些验证场景上的差值，不代表跨训练种子的显著性。

### 固定拓扑的含义

| 模型 | 场景10000终态覆盖／联网数 | 场景10001终态覆盖／联网数 |
|---|---:|---:|
| Baseline 1M / N3 | 55.33%／13 | 72.00%／18 |
| Baseline 1M / N4 | 74.67%／18 | 48.00%／16 |
| Baseline 1M / N5 | 82.67%／18 | 72.67%／18 |
| Baseline 1M / N6 | 67.33%／18 | 71.33%／18 |
| Baseline 1M / N7 | 50.67%／15 | 0.00%／0 |
| Baseline 1M / N8 | 78.67%／18 | 78.67%／18 |
| DPPO 10M best | 63.33%／18 | 74.67%／17 |

8邻居在这两个固定场景终态均有18架联网、78.67%覆盖，终态拓扑表现较好；但场景10001的t351→352仍有77.33%→4%的短暂崩落，110个失服务UE的原服务UAV全部同时断联。因此只看终态图会漏掉执行过程中的严重链路风险。
7邻居在场景10001终态聚集且全部失去BS可达性，覆盖为零。这说明观察槽位变多没有自动转化为维持网关接入的策略；也不代表7邻居设定必然失败，仍需多训练种子验证。
多个互不相连的UU分量若分别接入BS仍属合法服务拓扑，不能仅以UU图不连通判断部署失败。

| 5 | 2.52 | 2.46 | 9.84% | 4.04% | 115,908 |
| 6 | 2.60 | 2.57 | 4.88% | 1.87% | 122,052 |
| 7 | 2.46 | 2.45 | 1.53% | 0.40% | 128,196 |
| 8 | 2.58 | 2.58 | 0.17% | 0.03% | 134,340 |

这些可见率在各自策略产生的布局中统计，既受观测上限影响，也受策略的聚集／展开行为影响，不是严格同状态信息增益。新增邻居槽位仍限制在650m物理直连范围，补零不代表可观察远处UAV。

原3邻居在CPU训练，4–8邻居在CUDA训练；验证统一CUDA，但训练随机流和数值路径仍有差异。原3邻居历史CPU验证58.63125%，统一CUDA复验56.43844%，主表只使用后者；同一整数种子不保证CPU与CUDA高斯噪声相同。6／7／8邻居best复验覆盖、回报、吞吐与训练期验证一致（最大绝对差<1e-6）。

所有best均按完整回合任务回报（覆盖＋0.1吞吐）选择，不单独按覆盖最大化。本次没有另选模型。模型哈希、原始逐步数据、逐场景表、固定轨迹、MC预测及可重建来源保存在本目录。
