# 邻居观测3／4／5：1M baseline与10M参考比较

本轮仅冻结模型验证，不训练。32个验证场景10000–10031、动作采样种子880001、批次16、400步、CUDA FP32，关闭TF32。1M三组重新验证best和last；10M两组仅复用来源哈希一致、相同口径的best评估。不加入teacher或其他奖励消融组。

所有组奖励均为覆盖率＋0.1归一化吞吐，无鲁棒性与断联惩罚。主表按此前习惯展示各运行best；邻居数的同预算判断同时查看1M last。10M组预算不同，DPPO另有示范及预训练、服务评分关联和不同UE特征，不能将跨组差异单独归因于邻居数或算法。

原3邻居1M在CPU训练，4／5邻居在CUDA训练；本轮统一CUDA验证，但训练设备与采样随机流仍是额外差异。单训练种子只能提供当前运行的证据。下列区间按32场景配对bootstrap 2000次，种子950001；不是训练种子置信区间。

## 邻居数效应与稳定性

- best，4邻居−3邻居：平均覆盖+3.838pp，场景95%区间[+1.289, +6.244]pp。
- best，5邻居−3邻居：平均覆盖+4.242pp，场景95%区间[+1.606, +6.804]pp。
- last，4邻居−3邻居：平均覆盖+2.656pp，场景95%区间[+0.411, +4.915]pp。
- last，5邻居−3邻居：平均覆盖+2.696pp，场景95%区间[+0.843, +4.682]pp。
- Baseline 1M / 3 neighbors：平均覆盖曲线峰值t245、65.54%；后100步−51至150步为+1.19pp；32场景中32个出现≥10pp单步跌幅。靠边150m内6.98%，近邻<100m5.82%。真实直连度≥4／5的UAV时隙占比20.80%／9.12%；超出观测槽位比例20.80%。
- Baseline 1M / 4 neighbors：平均覆盖曲线峰值t224、67.48%；后100步−51至150步为+3.33pp；32场景中32个出现≥10pp单步跌幅。靠边150m内4.80%，近邻<100m4.00%。真实直连度≥4／5的UAV时隙占比22.48%／8.96%；超出观测槽位比例8.96%。
- Baseline 1M / 5 neighbors：平均覆盖曲线峰值t267、67.33%；后100步−51至150步为+1.96pp；32场景中32个出现≥10pp单步跌幅。靠边150m内4.99%，近邻<100m4.26%。真实直连度≥4／5的UAV时隙占比22.59%／9.84%；超出观测槽位比例4.04%。
- Baseline 10M best：平均覆盖曲线峰值t228、70.73%；后100步−51至150步为+11.09pp；32场景中31个出现≥10pp单步跌幅。靠边150m内3.25%，近邻<100m3.37%。
- DPPO 10M best：平均覆盖曲线峰值t258、70.04%；后100步−51至150步为+0.34pp；32场景中31个出现≥10pp单步跌幅。靠边150m内8.54%，近邻<100m4.16%。

当前运行支持‘增加邻居输入后平均服务能力有所改善’：best覆盖分别提高3.84、4.24pp；同预算last也分别提高2.66、2.70pp。但不代表全部收益已归因于观测信息，训练设备、随机流和第一层参数量也不同。

5邻居相对4邻居的best覆盖仅高0.404pp，last覆盖几乎相同；不能据此认定5邻居稳定优于4邻居。不过5邻居best平均断联率为8.84%，每回合≥10pp骤降次数从3邻居33.38降至17.56，表现出更好的稳定性迹象。最大跌幅差值的场景区间仍跨零，不能宣布极端骤降已解决。

4邻居和5邻居best的平均覆盖曲线峰值已分别位于t224、t267，本次结果不支持“所有策略都固定在100–150步达到峰值”的普遍结论。曲线均值后期较好也可能掩盖不同场景在不同时间发生的严重断链。

## 关键链路事件：看到邻居仍可能断链

4邻居best，固定场景10000的t199→t200：覆盖80%→14%，联网18→3架，失去服务的100个UE中97个原服务UAV同时断联。链路U2–U6距离635.5→683.0m，跨过650m阈值；两端此前互为第2／3近邻，均在4邻居输入内。同时U2–U10也失效，因此这次大幅下降与回传连通性破坏直接对应；并非全部由未观察到邻居造成。下一步覆盖恢复到79.33%、18架联网，因此这是短暂的大幅断链事件，并非该场景从此永久失去部署。

这支持进一步关注“已知链路的安全余量及协同保持”，但仍不足以证明当前失败只有一个原因。增加邻居数量没有直接表达下游依赖或强制约束相对运动，也没有改变回传阈值和任务奖励。

- Baseline 1M / 5 neighbors：本策略完整回合MC对比，critic RMSE 8.727、MAE 6.633、偏差-2.639。
