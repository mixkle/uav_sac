# 固定布局关联诊断报告

本实验仅运行冻结策略和固定转移的影子关联，无网络训练、无补位闭环反馈。

源模型：`runs/mappo_coverage_throughput_capacity10_1m_seed0/best.pt`；best实际训练步数 **671,744**，源运行完成1,000,000步，训练奖励为 **覆盖+0.1×归一化数据率**。

共32个验证/诊断场景、12,800条联合转移；随机评分每转移重复20次。教师实际轨迹平均覆盖 **58.631250%**。

本次影子容量 **10 UE/UAV**，原轨迹采集容量 **10**，链路速率按现有资源公式乘以 **1**。轨迹来自该容量真实训练的策略，本轮没有临时更改容量或缩放链路速率。

使用源模型的原观察、历史、集中关联生成轨迹；影子任务奖励按 **覆盖+0.1×归一化数据率** 计算。鲁棒性和断联仍单独记录，不会在零权重时计入收益。

## 缺口与结论

- **teacher**：协议可避免损失0.203047人/步，补位恢复0.090078，回收比例44.36%；剩余重分配缺口0.112969，评分时序缺口4.969766，物理与容量残余缺口62.050625。
- **constant**：协议可避免损失0.793359人/步，补位恢复0.596484，回收比例75.18%；剩余重分配缺口0.196875，评分时序缺口4.969766，物理与容量残余缺口62.050625。
- **random**：协议可避免损失0.787824人/步，补位恢复0.572648，回收比例72.69%；剩余重分配缺口0.215176，评分时序缺口4.969766，物理与容量残余缺口62.050625。

协议缺口是同一已评分候选图下的可避免损失；时序缺口来自运动后新增但尚未评分的合法边；残余缺口综合感知、下行、回传、布局及容量，不据此认定某一个物理因素为唯一根因。

评分造成的服务归属变化不一定改变服务人数，但可能改变吞吐和故障保留；完整任务判断应结合绝对收益变化，不只看“发生改变”的频率。

本结果只适用于冻结教师访问的布局分布；不能推断扩散模型最终性能，也不能把影子补位收益当作闭环部署收益。
