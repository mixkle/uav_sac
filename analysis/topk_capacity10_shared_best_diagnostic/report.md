# 固定布局关联诊断报告

本实验仅运行冻结策略和固定转移的影子关联，无网络训练、无补位闭环反馈。

源模型：`runs/continuous_mappo_coverage_shared_central_history_resumed_400k_seed0/best.pt`；best实际训练步数 **561,792**，源运行完成1M、采用纯覆盖奖励。

共32个验证/诊断场景、12,800条联合转移；随机评分每转移重复20次。教师实际轨迹平均覆盖 **68.163385%**。

本次影子容量 **10 UE/UAV**，原轨迹采集容量 **20**，链路速率按现有资源公式乘以 **2**。原教师覆盖只用于核对记录来源，不代表新容量策略的表现。

场景与baseline一致，使用源模型的原观察、历史、集中关联生成轨迹；影子完整任务奖励按覆盖+0.1吞吐+0.5鲁棒性−0.1断联计算。

## 缺口与结论

- **teacher**：协议可避免损失0.203125人/步，补位恢复0.090234，回收比例44.42%；剩余重分配缺口0.112891，评分时序缺口4.442578，物理与容量残余缺口54.974219。
- **constant**：协议可避免损失0.880078人/步，补位恢复0.682500，回收比例77.55%；剩余重分配缺口0.197578，评分时序缺口4.442578，物理与容量残余缺口54.974219。
- **random**：协议可避免损失0.870914人/步，补位恢复0.638715，回收比例73.34%；剩余重分配缺口0.232199，评分时序缺口4.442578，物理与容量残余缺口54.974219。

协议缺口是同一已评分候选图下的可避免损失；时序缺口来自运动后新增但尚未评分的合法边；残余缺口综合感知、下行、回传、布局及容量，不据此认定某一个物理因素为唯一根因。

评分造成的服务归属变化不一定改变服务人数，但可能改变吞吐和故障保留；完整任务判断应结合绝对收益变化，不只看“发生改变”的频率。

本结果只适用于冻结教师访问的布局分布；不能推断扩散模型最终性能，也不能把影子补位收益当作闭环部署收益。
