# 冻结baseline：跳数速度缩放＋局部链路安全约束

使用3邻居、容量10、覆盖＋数据率baseline 1M的best（实际671,744步）。本轮不训练，不修改模型、生产环境工厂或训练配置。

## 用户确认的规则

- 跳数缩放沿用alpha_min=0.25、k=0.4；合法联网跳数1–18，断联标记19，断联alpha=1。
- 安全裕量delta=5m，UU安全距离为645m，物理通信距离仍为650m。
- 多跳联网节点仅从当前可见3邻居中选择严格更低跳数的邻居，优先最小跳数，平局按距离和编号。无此邻居时跳过约束并记录；不读取不可见节点或上游动作。
- 直连BS的UAV跳过UU安全约束；不新增UAV–BS安全距离限制。
- 只调整运动幅度，不改变actor方向；保持原始动作历史。
- 所有节点同时独立决策，约束使用上游**动作前**位置。
- 无可行缩放解时s=0并记录不可行；这并不意味着已经满足安全距离。

令r=p_i−p_j，v为actor原始指令对应的位移，则解一维二次不等式：

`(v·v)s² + 2(r·v)s + r·r − 645² <= 0`，`0 <= s <= alpha(h)`。

解析得到可行区间后取其最大端点；不通过粗糙的步长枚举近似。原位在安全圈外但动作向内时，也检查是否可以进入安全圈，不直接冻结。零动作、切线、空可行集均有明确处理。

## 固定条件与验收

统一CPU8线程、Numba4线程，32场景10000–10031、16环境批次、动作种子880001、400步。原速度和仅跳数缩放复用上一轮来源一致的数据；新组在相同初始布局、UE完整路径和动作随机状态序列下运行。三组首步原始动作一致，后续状态改变会使actor输出改变。

代码位于 `src/uav_research/link_safety_diagnostic.py`，只被独立诊断入口使用。9项相关测试通过，覆盖解析最大解、随机小样本与密集网格对照、局部父节点选择、动作历史、恢复、批量与标量一致、以及“静止上游公式成立但上游移动后实际断边”的反例。

两个代表场景共800步另行逐UAV核对可见邻居、最低跳数选择、最大可行s、动作历史和公式约束。报告见[完整结果](../analysis/baseline3_best_hop_speed_link_safety_delta5/report.md)，验收为同目录 `verification.json`。

## 结果

| 指标 | 原速度 | 仅跳数减速 | 跳数减速＋安全约束 |
|---|---:|---:|---:|
| 平均覆盖 | 58.631% | 57.730% | 59.358% |
| 后100步覆盖 | 61.021% | 64.007% | 64.691% |
| 终态覆盖 | 61.500% | 64.583% | 62.771% |
| 平均吞吐Mbps | 481.47 | 472.20 | 485.81 |
| UAV断联率 | 11.741% | 9.561% | 7.414% |
| 最大单步覆盖跌幅均值 | 46.875pp | 35.063pp | 27.771pp |
| 每回合≥10pp单步骤降次数 | 28.94 | 24.66 | 12.94 |
| 实际速度m/s | 15.86 | 8.42 | 7.46 |

相对仅跳数减速，平均覆盖+1.628pp、吞吐+13.61Mbps、断联−2.147pp、最大单步跌幅−7.292pp；这些2000次配对场景bootstrap区间未跨零。后100步覆盖+0.684pp及终态−1.812pp的区间均跨零，不认为各阶段都改善。不是训练种子置信区间。

112,727个UAV时隙选到了上游；7,839次无可行解，占6.95%，按规则停住；7,825次多跳节点因可见邻居中没有更低跳数节点而跳过。

对判为可行的动作，执行相对上游旧位置的645m约束违规为0。但双方移动后仍有1,915个所选父边时隙超过650m，其中739次原本存在可行解。计数包含同一链路在多个时隙重复发生，并非1,915个独立场景。

5m裕量无法覆盖上游的最坏位移：即使上游直连BS，其最大位移也可达7.5m；多跳上游可能更大。因此当前规则仍不是动作后连通性保证。约束还没有处理网关离开BS接入范围、无可见上游或已在缓冲区外等情形。

原速度58.63125%对应CPU历史口径，本轮没有混用之前CUDA的56.43844%。

## 原t151断链案例的同起点检查

对上一轮场景10000的t150位置、下一步保存的actor动作和t151 UE位置只做一次过滤与关联重算：U12选U9为上游，原距离648.60m已超过645m，沿actor方向无可行解，因此U12取s=0。结果18架联网、覆盖68%，原事件为9架联网、31.33%覆盖；U9–U12动作后646.37m。

这次靠不可行时停住的回退避免了原断链，没有满足645m目标；不能记作公式可行成功。它是同起点单步诊断，与新组从t0完整运行后的t151布局不同。数据保存在 `old_event_one_step.json/.npz`。

## 命令

从保存数据重建报告和同起点检查，不重新采样：

```bash
.venv-dppo-compat/bin/python scripts/diagnose_link_safety.py --rebuild
```

需要重新执行时使用新的输出目录，避免覆盖：

```bash
OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=8 OMP_NUM_THREADS=8 \
.venv-dppo-compat/bin/python scripts/diagnose_link_safety.py \
  --output analysis/baseline3_link_safety_delta5_repeat
```

本轮只得到冻结策略的执行干预证据，不等同于按新动力学重新训练的收益。
