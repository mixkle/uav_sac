# 纯覆盖 C 组：冻结 actor，使用 MC Return 单独拟合 critic

实验以 `runs/mappo_ablation_c_mobile_coverage_250k_seed0/last.pt` 为起点。目标是检查：固定策略并提供完整回合标签后，现有 MLP 能否拟合回报，以及这种拟合能否推广到新场景。

前一个实验表明单独关闭 Value Clipping 没有修复严重的末端高估，但它仍可能影响误差幅度，不能据此断言完全没有影响。本实验继承原 C 组而非无裁剪训练组的 actor、critic 和 Adam。

## 设置

| 项目 | 本实验 |
|---|---|
| actor | C组250k的last，全部参数冻结，包含UE编码器；按原分类分布采样 |
| 场景与奖励 | 原C组移动UE场景；奖励仅实际联网服务覆盖率 |
| critic | 保留6292→256→256→1，两层ReLU；包含原有t/400输入 |
| 初始值与优化器 | 继承源critic权重与Adam历史；学习率5e-4、Adam eps=1e-5 |
| 目标 | 完整400步回合的MC折扣回报，γ=0.995，终止之后价值0 |
| 损失 | 归一化Huber，δ=10；没有Value Clipping |
| 归一化 | 只用拟合标签重新估计PopArt统计并保持初始原始预测；随后冻结统计量 |
| 梯度裁剪 | 范数0.5，保持现有设置 |
| 训练预算 | batch512，每轮50次更新；300轮、15000次critic更新，无早停 |
| 模型选择 | 独立选模场景的全程原始RMSE，包含epoch0；同时报告末轮 |
| CPU设置 | 与C组一致：PyTorch8线程、Numba4线程 |

动作前的状态与动作后的奖励配对：

\[
G_{399}=r_{399},\qquad G_t=r_t+0.995G_{t+1},\qquad G_{400}=0.
\]

标签不依赖任何critic预测，不使用GAE或片段末尾bootstrap；每条完整回合结束后才计算。训练中只调用critic优化器，不调用MAPPO更新入口。

## 数据隔离与检查

| 划分 | 场景种子 | 动作种子 | 完整回合数 | 联合转移数 |
|---|---|---|---:|---:|
| 拟合 | 61000–61063 | 930001 | 64 | 25600 |
| 选模 | 62000–62015 | 930002 | 16 | 6400 |
| 独立检查 | 63000–63031 | 930003 | 32 | 12800 |

三组不重叠，与原32个验证场景和100个保留测试场景隔离。每个场景采集一条随机策略轨迹，不筛选表现。状态按float32 memmap保存，回报用float64计算；全部状态约1.05 GiB，分批加载，不把完整数据复制为训练Tensor。

检查奖励逐步等于coverage、真正终止发生于400步、最后标签等于最后奖励、时间特征匹配动作前时刻、actor哈希不变、源检查点和数据哈希不变。记录每轮训练loss、拟合/选模原始RMSE及末步误差；训练完成后才计算末轮/选中模型在独立检查集的误差。

输出前100步、中间100步（150–249）、最后100步、最后20步和最后一步指标。另以“拟合集每个时刻的平均MC回报”作为不用检查标签拟合的时间参照，不更改MLP或训练流程。

## 如何回答实验问题

1. **拟合集与独立检查集都好：** 现有MLP在固定策略下有拟合能力，在线目标、数据分布变化或优化流程值得重点排查；尚不能唯一归因于GAE。
2. **拟合集好、检查集差：** 现有MLP可以学习给定标签，但跨场景泛化或时间规律学习不足，不能笼统称其没有表达能力。
3. **拟合集也差：** 当前初始化、优化器和预算没有实现拟合；仍不能证明网络不存在能拟合的参数。需继续控制优化与结构变量。

单轨迹MC回报是带采样噪声的实际实现值，不是精确条件期望V。全回合平均误差可能掩盖前期低估与后期高估，必须结合末端上界1和分时曲线判断。

与在线训练相比，本实验同时固定actor、固定数据、替换目标、固定目标统计并改变样本复用次数。MC拟合成功不能直接证明GAE公式错误，MC拟合不佳也不能排除GAE反馈的影响。继承Adam历史保留了原优化路径的影响，若失败，不能立即归因为MLP结构。

## 本次结果（2026-10-20）

300轮、15000次critic更新完成，耗时449.9秒，峰值RSS约1965 MiB。按选模集全程RMSE选中epoch184，另保留epoch300末轮。

| 指标 | 原critic | MC拟合末轮 |
|---|---:|---:|
| 拟合集全程RMSE | 22.795 | 0.538 |
| 拟合集末步RMSE | 54.302 | 0.383 |
| 独立检查集全程RMSE | 22.214 | 16.560 |
| 独立检查集末步RMSE | 53.148 | 32.812 |
| 独立检查集末步预测均值 | 53.200 | 31.039 |

独立检查集末步实际回报均值为0.339。选中模型的检查集全程RMSE为16.777、末步预测均值30.561，同样没有解决末端问题。只用拟合集各时刻平均回报作为时间参照，检查集全程RMSE为7.130、末步RMSE为0.100。

现有MLP在拟合集已经能拟合弯曲的MC曲线，无法用“只能学习直线”解释结果；当前更突出的证据是跨场景泛化差。高维场景特征与单一时间特征混在同一MLP中，可能使网络利用场景相关性拟合已见轨迹，却未学到可迁移的剩余时长规律；本实验尚未独立证明这一机制。

冻结源critic的GAE标签与MC之差：完整回合λ=0.95标签RMSE为18.795，128步片段标签RMSE为20.618；λ=1完整回合与MC一致。说明bootstrap目标会保留源预测误差，但MC标签训练后检查集仍严重失准，GAE不能作为唯一解释。

7项相关pytest通过；额外只读目标诊断通过λ=1/MC一致性及终止标签检查。actor、源文件、数据及固定归一化统计的校验通过。未更新actor或原C组在线训练权重。
