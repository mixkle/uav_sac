# 共享与独立actor实验：保留的1M以上结果

共享actor与独立actor均采用集中式团队时间因子V和团队优势，奖励仅为覆盖率。独立组不是标准IPPO。场景、观察和动作与当前完整奖励baseline相同，奖励权重不同。

|实验|预算|全回合覆盖|后100步覆盖|终态覆盖|
|---|---:|---:|---:|---:|
|共享last|1M|64.94%|68.77%|69.21%|
|独立last历史切片|1M|58.44%|63.31%|64.67%|
|独立last|1.2M|61.79%|67.55%|67.03%|

这是固定验证场景下的单训练种子结果。独立组追加训练有改善，但1.2M与共享1M不是同预算比较。

运行、报告及检查点路径见[结果目录](results_inventory.md)。复现配置为 `configs/mappo_coverage_shared_1m.yaml` 和 `configs/mappo_coverage_independent_1p2m.yaml`；两者从头运行，不继承任何权重。

旧100k/400k结果已清理。报告文件保留1M与1.2M数据；重新分析时显式传入现存的共享 `resumed_400k` 运行目录，不能使用已删除的原共享100k目录。

下一轮正式研究使用[完整奖励baseline](training_workflows_and_parameters.md)，不要将纯覆盖模型直接续训为完整奖励实验。
