# 模型实现约定：beacon-set-v2

连续版本以 `ENVIRONMENT MODELING.md` 为准；离散MAPPO使用独立建模文档与论文规模场景，见末节。主任务是 UAV 全区域随机初始化、局部发现和服务优化。现有训练产物和分析已清理；旧观察格式检查点拒绝加载，无权重迁移。

## 连续版本场景与初始化

1600×1600 m，16 UAV、180 UE，BS 为 (0,0,0)、(0,1600,0)。UAV 高度 100 m，水平坐标在完整区域独立均匀采样；不按连通性、覆盖或网关接入筛选。UE 使用四中心等权截断二维高斯混合：中心为 (480,480)、(1120,480)、(480,1120)、(1120,1120) m，每轴标准差128 m，初始范围[160,1440]²。分量独立随机选择，人数不强制每组45；固定所属分量，仅对越出内部范围的样本重采样，无坐标裁剪或服务筛选。对应配置为margin_fraction=.10、std_fraction=.08、centers=[.3,.3]/[.7,.3]/[.3,.7]/[.7,.7]，按各轴区域尺寸缩放。留白仅作用于初始坐标，运动仍在完整区域反射。

分布类型参考论文 *Scalable UAV Multi-Hop Networking via Multi-Agent Reinforcement Learning with Large Language Models* 第V-A节（PDF第11页）；该论文未指定留白、中心和标准差，本实验的数值不能标为原文参数。初始允许全部断网或零覆盖。静止 baseline 保持随机初始位置。`uav_initialization=bs_launch` 仅供历史复现；包含 launch_radius 但缺失模式字段的历史配置按旧出发分布解释，新配置显式指定 uniform。UE 每秒独立采样有符号高斯幅度（σ=1，截断±3 m/s）与均匀方向，越界反射。

UU 距离≤400 m，UG 三维距离≤350 m。B 的每列是仅通过 UAV 中继到一个 BS 的最短跳数，直连为1，不可达为U+1。BS 不参与转发，多个子网分别可达 BS 即可服务。两个 BS 始终可用。

## 无线与关联

上下行共用平均 dB 路径损耗，仰角单位为度。LoS 9.61/0.16、额外损耗1/20 dB为工程假设，不代表场景实测；正式论文仍需说明适用环境。下行2 GHz、20 MHz、每机30 dBm，总功率均分20子带，子带噪声按−174 dBm/Hz和NF9 dB计算。其余所有 UAV 均产生满负载同频干扰，与当前关联、是否断网无关。

上行发现信标功率0 dBm、带宽180 kHz、UAV NF9 dB，噪声−112.447 dBm。信标间干扰忽略，且与下行正交。SNR≥5 dB即发现；没有硬编码感知半径。断网 UAV 仍能发现 UE。

关联候选必须同时满足发现、下行SINR≥−3 dB、任一 BS 可达。沿用 UE 按候选数量、ID 排序，候选 UAV 按SINR、ID排序的容量贪心规则，每 UAV≤20用户。每 UE 最多关联一架 UAV。四阶段诊断按用户逐步筛选，未发现、无达标下行、无可达候选、容量未分配四组互斥，与已服务人数之和为 M。

## 奖励（2026-10-14更新）

两种算法共用环境，在动作、位置、拓扑和关联更新后计算团队奖励：
\(r=\rho+w\tau+\lambda J-\mu D\)，其中
\(D=U^{-1}\sum_u\mathbf1[\min_gb_{u,g}>U]\)。直接或多跳到任一BS即为可达；多个子网分别接入BS不会被惩罚。D是当前断联比例，不是新增断联人数或故障诊断比例。

当前YAML均显式设置 `disconnection_weight: 0.1`，作为原文未指定数值时的可调整起点，并非最优调参值。SAC保持w=0.1、lambda=0.5；离散MAPPO主配置w=0.1、lambda=0，WSL配置当前w=0。两种算法直接使用同一个环境返回值，不再次扣惩罚。允许负奖励，不裁零。旧配置/检查点缺失该字段时按mu=0解释，旧回报不改写；已有续训配置检查会拒绝跨奖励权重续训。

日志记录 `disconnection_ratio`（D）及 `disconnection_penalty`（mu D，正数）；评估保存平均、终态及最后100步。轨迹 `reward_terms` 为[ρ,τ,J,D]，`reward_contributions`为[ρ,wτ,lambda J,−mu D]，`reward`为实际团队奖励。零奖励和负奖励分别统计；首次正奖励与首次服务分开。CLI训练可用 `--mu-disconnect` 覆盖权重。

## 原始观察、状态与动作

`RawObservation(fixed, users, offsets)` 的固定数组末两维是 `[U,F]`；UE数组 `[L,4]`，偏移有全部组数+1个元素。环境批次、回放批次共用堆叠/选择/重置接口。重复采样和全空批次仍保留所有分组。

固定部分为自身 `[x,y,h,c,n,A_i]`、全部BS的先验xy坐标、三个最近直接邻居 `[ID,x,y,h,c,n,A_j]`。自身5+U维，BS2G维，邻居3(6+U)维，主配置共91维。坐标除区域尺寸，高度归一为1，跳数除U+1，服务人数除容量，邻居ID为(ID+1)/U，空槽零；邻居按距离、ID排序。

UE行是相对xy/区域尺寸、上行SNR/30 dB、本机服务标记，按UE ID排列但策略集合置换不变。保留全部已发现UE。编码器4→32→32 ReLU，分组求均值，空组为零，再拼接人数/容量20；不按全局M归一，人数允许大于1。编码后124维。只观察当前发现，不记忆历史UE；累计发现仅写诊断。

全局状态仍为所有节点3D坐标、A/B/C/Y、t/T，共6643维；不额外加入发现矩阵或编码结果。下行Y不因关联候选过滤而改写。actor不读取全局状态或时间。

高斯隐变量径向变换 a=z/√(1+||z||²)，log|det J|=−2log(1+||z||²)。环境把归一化指令乘10 m/步，再裁剪位置。回放与critic使用指令，实际位移单独记录。MAPPO保存latent z，逐agent计算PPO比。600步是真终止，不bootstrap；采集片段结束不是真终止。

## 算法与数据完整性

SAC共享局部actor、集中双critic、联合熵，编码器属于actor优化器；critic目标和温度更新不更改编码器。SAC没有目标actor；MATD3目标actor含独立目标编码器；MAPPO每轮从原始rollout重新编码。主干256×256，编码器32×32，默认γ=.995，SAC actor/critic/temp学习率1e-4/3e-4/1e-4，α=.01，目标熵−2U。其余值见展开的运行config.yaml。

回放固定字段预分配，变长UE按联合转移各一个连续数组，入池复制。固定及原始集合一一对齐，下一观察在环境reset前保存。50k最坏全可见原始存储约7.33 GiB，运行与优化器另计。启动报告预算，每轮检查RSS上限，超限明确报错；不静默删除UE/缩小回放。

`resume_XXXXXXXXXXXX/` 为完整目录：CPU Tensor分块（最多256条）、SHA256索引、元数据含优化器、环境、RNG、回放游标、历史最佳。临时目录完整写完后原子发布，保留最近两份；恢复逐块读取释放。保存失败不替换上一份，验证/完整保存前写轻量last.pt。actor导出只包含编码器、策略、缩放及拓扑规格，不需要critic或全局用户数。

## 故障指标与评估

每步精确删除每架 UAV 后重算剩余节点到各 BS 的可达性，保持关联和名义SINR固定，失败机用户丢失，其余用户在所属机仍可达任一 BS 时保留。J是逐故障覆盖平均，0≤J≤(1−1/U)ρ。任务保留比q=ΣJ/Σρ，零覆盖任务单独报告。双BS可达不表示节点独立冗余。

验证默认32个场景10000–10031，测试100个20000–20099，校准30000起独立随机流；不同策略共享UE运动。评估给全任务、终态、最后100步指标。短流程验证只用小验证子集，不碰保留测试集；未经通知不进行正式训练或多种子。熵探索不保证学到协调展开，短训可运行不是算法优势证明。

## 并存的九动作 MAPPO 版本

新配置env.action_space=discrete9、algo.name=mappo；缺失action_space的历史配置按continuous解释。世界坐标前=+y、右=+x；动作0–8依次为前/后/左/右/左前/左后/右前/右后/悬停，八个移动动作等速，斜向分量为1/√2。标量输入整数[U]、向量输入[E,U]；连续接口保留。无边界动作掩码，概率对应原始指令。

新版场景3500×3500 m、18 UAV、150 UE、3 BS（左下、左上、右下）；UAV及UE全区域独立均匀reset，不做服务筛选。100 m高度为补充假设；每步30 m、400步真终止。固定观察101维、编码后134维、全局状态6292维，UE集合和物理计算共用参数化实现。

离散无线配置为2.4 GHz、上下行NF15 dB；下行仍总20 MHz/1 W均分20子带、满负载SINR≥−3 dB；独立180 kHz信标功率0.4 W、SNR≥20 dB发现。UU650 m、UG三维1500 m为校准后的距离近似。奖励ρ+wτ−mu D，主配置w=0.1、mu=0.1，WSL配置当前w=0；鲁棒性权重0，J只作诊断。论文参数与补充假设在完整参数文档中区分，未照搬论文无干扰25 dB SNR模型。分类actor使用精确熵、逐agent PPO概率比和团队GAE；集中式V(s)不读联合动作。不使用回放池或SAC温度。检查点及导出标注world-nine-v1/categorical，仅在完整rollout更新安全点完整保存。

完整独立说明见 [离散建模](../ENVIRONMENT%20MODELING%20DISCRETE%20MAPPO.md)，训练流程和全部参数见 [参数说明](training_workflows_and_parameters.md)。两版本结果分别保存，不聚合为同一训练方法。
