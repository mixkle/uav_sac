# 当前研究 baseline 实现约定

当前baseline入口是 `configs/mappo_coverage_throughput_capacity10_1m.yaml`：容量10、覆盖与数据率两项奖励。历史容量20四项奖励的 `mappo_full_reward_baseline_1m.yaml` 继续保留。具体数值以配置及[参数表](training_workflows_and_parameters.md)为准。新增扩散DPPO使用独立的5维UE观察和Top-K协议，详见[扩散实验说明](diffusion_dppo_experiment.md)；下文描述原Gaussian MAPPO baseline。

## 环境

3500 m方形、18 UAV、150移动UE、三个角落BS；UAV全区域均匀初始化，UE仅初始化时限制在中心2500 m方形。运动发生在整个场地。回合400步真终止，不bootstrap；rollout片段结束仍bootstrap。

BS只作接入终点，不通过BS–BS或核心网隐藏转发。只需可达任一BS，允许多个互不相连但各自联网的UAV子网。UAV–BS距离使用三维距离，UAV–UAV使用等高水平距离。

上下行共用平均路径损耗。发现使用独立上行信标SNR，无需先联网；实际服务还需下行SINR、核心网可达与容量条件。保留满负载下行干扰、唯一关联、容量贪心及固定关联单UAV故障评估。

## 观察与动作

结构化观察保存固定数组、全部发现UE的连续集合和偏移。相对坐标模式下，自身坐标按区域尺寸归一化，BS与邻居为相对本机偏移；UE也是相对位置。集合行包含相对xy、SNR/30、本机服务标记，均值编码并拼接人数/10。无可见UE时集合编码为零。

固定观察105维，包含4维一步历史：上一归一化指令xy、上一最短跳数/(U+1)、上一感知人数/10。执行动作前记录当前跳数与感知人数，下一观察携带它们及刚执行的指令。reset时动作历史为零，其余取初始状态值；刷新无线不推进历史。历史不跨回合，快照完整保存历史。

actor共享、状态相关高斯。`a=z/sqrt(1+||z||²)`，log Jacobian为`−2log(1+||z||²)`。动作乘30 m后边界反射；log概率对应原始指令，实际位移单独记录。PPO在同一latent上重算逐UAV概率比，不将18个概率比相乘。

## 奖励与价值

当前奖励为 `r=rho+0.1*tau`，鲁棒性、断联及边界权重为零。tau为总速率除以`M*5 Mbps`；J仍作为逐故障保留覆盖诊断，固定关联、不重新关联用户。所有actor使用同一团队奖励和团队优势。

集中式critic输入6292维物理状态，包括`t/400`，输出`V=H_t*m(s)`，H为剩余动作次数对应的折扣和。m是未来折扣平均任务奖励，允许负值及超过1，不加sigmoid或范围裁剪。GAE读写累计价值；平均奖励与累计价值使用各自归一化，平均奖励PopArt重标定输出层与Adam，损失及Value Clipping在累计价值空间。

critic未读取actor的一步历史，这一既有限制仍需在后续MC诊断中关注。熵正则只用于MAPPO actor，不加入MC价值标签。

## 数据完整性

rollout保存原始集合副本、latent、旧log概率、累计价值、奖励及终止字段，下一观察先于reset保存。MAPPO没有回放池。完整恢复包括模型、优化器、两套归一化、环境及全部随机状态，原子发布、保留最近两份。跨观察、动作、共享模式或奖励配置续训拒绝。

固定32场景用于验证选模，100个测试场景保留。采样验证、best按全回合完整任务回报选择；同时报告last及各项物理指标。只做一个训练种子时，场景bootstrap不能标为训练种子置信区间。
